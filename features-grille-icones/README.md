# Grille de fonctionnalités à icônes

Six fonctionnalités en grille, chacune avec une icône, un titre et une courte description.

![Grille de fonctionnalités à icônes](apercu.webp)

**[Voir la démo et la fiche complète sur Forge](https://forgefrance.fr/composants/features-grille-icones?utm_source=github&utm_medium=readme)**

## Formats

| Dossier | Contenu |
|---|---|
| `html-css/` | HTML + CSS natif, sans dépendance (ouvrir `index.html`) |
| `html-tailwind/` | Même composant en classes Tailwind CSS |
| `react/` | Composant React TypeScript (`IconFeatureGrid.tsx`) |

Personnalisation : modifiez les variables CSS en tête de fichier (couleurs, rayons, typographie) ; le thème sombre suit.

La version WordPress (bloc / extension) est téléchargeable gratuitement [sur la fiche Forge](https://forgefrance.fr/composants/features-grille-icones?utm_source=github&utm_medium=readme).
