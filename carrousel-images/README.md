# Carrousel d'images

Un carrousel de photos avec précédent, suivant, puces et bouton pause, qui ne défile jamais tout seul si l'utilisateur limite les animations.

![Carrousel d'images](apercu.webp)

**[Voir la démo et la fiche complète sur Forge](https://forgefrance.fr/composants/carrousel-images?utm_source=github&utm_medium=readme)**

## Formats

| Dossier | Contenu |
|---|---|
| `html-css/` | HTML + CSS natif, sans dépendance (ouvrir `index.html`) |
| `html-tailwind/` | Même composant en classes Tailwind CSS |
| `react/` | Composant React TypeScript (`ImageCarousel.tsx`) |

Personnalisation : modifiez les variables CSS en tête de fichier (couleurs, rayons, typographie) ; le thème sombre suit.

La version WordPress (bloc / extension) est téléchargeable gratuitement [sur la fiche Forge](https://forgefrance.fr/composants/carrousel-images?utm_source=github&utm_medium=readme).
