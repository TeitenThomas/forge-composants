# Bouton en relief

Un bouton épais qui s'enfonce sous le doigt, pour les actions principales.

![Bouton en relief](apercu.webp)

**[Voir la démo et la fiche complète sur Forge](https://forgefrance.fr/composants/bouton-relief?utm_source=github&utm_medium=readme)**

## Formats

| Dossier | Contenu |
|---|---|
| `html-css/` | HTML + CSS natif, sans dépendance (ouvrir `index.html`) |
| `html-tailwind/` | Même composant en classes Tailwind CSS |
| `react/` | Composant React TypeScript (`RaisedButton.tsx`) |

Personnalisation : modifiez les variables CSS en tête de fichier (couleurs, rayons, typographie) ; le thème sombre suit.

La version WordPress (bloc / extension) est téléchargeable gratuitement [sur la fiche Forge](https://forgefrance.fr/composants/bouton-relief?utm_source=github&utm_medium=readme).
