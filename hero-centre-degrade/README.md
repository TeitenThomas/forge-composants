# Section d'accueil centrée à dégradé

Un titre centré sur un fond dégradé doux, avec deux actions et une ligne de réassurance.

![Section d'accueil centrée à dégradé](apercu.webp)

**[Voir la démo et la fiche complète sur Forge](https://forgefrance.fr/composants/hero-centre-degrade?utm_source=github&utm_medium=readme)**

## Formats

| Dossier | Contenu |
|---|---|
| `html-css/` | HTML + CSS natif, sans dépendance (ouvrir `index.html`) |
| `html-tailwind/` | Même composant en classes Tailwind CSS |
| `react/` | Composant React TypeScript (`GradientCenteredHero.tsx`) |

Personnalisation : modifiez les variables CSS en tête de fichier (couleurs, rayons, typographie) ; le thème sombre suit.

La version WordPress (bloc / extension) est téléchargeable gratuitement [sur la fiche Forge](https://forgefrance.fr/composants/hero-centre-degrade?utm_source=github&utm_medium=readme).
